## 2024-05-15 - Proper Placement of Confirmation Dialogs and SVG Accessibility
**Learning:** Destructive actions with early returns for authentication checks (`if (!auth) return;`) will silently fail local testing if the user is unauthenticated. Additionally, icon-only buttons need strict accessibility markup (`aria-label` and `aria-hidden` on the SVG) and visible focus rings (`focus-visible:ring-2`) to be usable by keyboard users.
**Action:** Always place UI confirmation dialogs (`window.confirm`) *before* any backend or authentication early returns so the UI interaction can be tested independently of the backend state. Always ensure icon-only buttons have descriptive `aria-label`s, hide purely decorative child elements like SVGs using `aria-hidden="true"`, and apply `focus-visible` outline classes.
