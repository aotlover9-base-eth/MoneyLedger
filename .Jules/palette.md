## 2026-07-28 - Focus States and Confirmations for Destructive Actions
**Learning:** In this application, destructive actions like deleting an entry were missing proper keyboard accessibility (focus states) and confirmation dialogs. This poses a risk for accidental data loss, especially since the UI doesn't have an "undo" feature. The focus rings using `focus-visible` are critical for users navigating via keyboard.
**Action:** Always wrap destructive Firebase actions (like deletes) in a `window.confirm()` or equivalent dialog to prevent accidental data loss. Furthermore, ensure all interactive elements, particularly icon-only buttons, have an `aria-label` and use `focus-visible:ring-2` with appropriate offset and color classes (e.g., `focus-visible:ring-red-500`) to support keyboard navigation.
