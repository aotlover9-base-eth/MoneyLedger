## 2026-08-29 - Accessible Destructive Actions & Keyboard Focus
**Learning:** Icon-only buttons (like the delete trash can) are completely inaccessible to screen readers without `aria-label`, and the inner purely decorative `<svg>` must have `aria-hidden="true"` to prevent erratic reading. Furthermore, destructive actions (like Firebase document deletion) can be accidentally triggered via rapid clicking or keyboard navigation if not protected by a confirmation dialog (like `window.confirm`). Keyboard-only users also cannot navigate effectively if interactive elements lack explicit focus styles (`focus-visible:ring`).
**Action:** Always add `aria-label` to icon-only buttons, hide decorative child `<svg>` elements with `aria-hidden="true"`, protect destructive actions with `window.confirm`, and ensure explicit `focus-visible` styles are added for keyboard accessibility.
