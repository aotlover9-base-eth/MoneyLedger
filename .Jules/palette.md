## 2024-05-24 - Accessibility and UX for Destructive Actions
**Learning:** When dealing with destructive actions like deleting a database entry, two things are crucial: 1. Always prompt the user for confirmation (e.g., using `window.confirm`) to prevent accidental data loss. 2. Ensure icon-only buttons are fully accessible by providing an `aria-label`, adding `aria-hidden="true"` to purely decorative SVGs so screen readers ignore them, and implementing clear focus states (`focus-visible`) for keyboard navigation.
**Action:** When adding or modifying interactive UI components, especially for destructive operations, always wrap the action in a confirmation dialog and explicitly verify keyboard accessibility (focus styles) and screen reader support (ARIA labels, hidden decorative elements).
