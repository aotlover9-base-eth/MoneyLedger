## 2024-05-18 - Improved Delete Entry Button UX and Accessibility
**Learning:** In this application, destructive actions like deleting an entry previously occurred immediately on click without any confirmation or accessibility context for screen readers. Furthermore, testing local unauthenticated states revealed that UI interactions requiring Firebase Auth can hang or fail silently.
**Action:** When adding destructive action confirmation dialogs (e.g. `window.confirm`), place the prompt *before* any early returns that check for authentication (e.g. `if (!userId) return;`). This ensures the prompt can be tested locally using mock data even without auth. Additionally, always add `aria-label` to icon-only buttons and `aria-hidden="true"` to their child SVGs, and ensure proper keyboard focus states (`focus-visible:ring-2` etc.) are implemented using existing Tailwind classes.
